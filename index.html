JavaScript

JS é uma linguagem de programação orientada a objetos. E o que isso quer dizer? Significa que seus próprios tipos definem métodos para trabalhar em vez de funções globais para operar em valores de vários tipos.



Tipos, valores e variáves

Tipos subdividem-se em tipos primitivos ou tipos de objetos. Tipos primitivos incluem strings, booleanos e tipos especiais (null e undefined).

Objetos são quaisquer valores que não sejam de tipos primitivos. Um objeto é um conjunto de propriedades em que cada propriedade tem um nome e um valor. Tipos especiais de objetos: Array (conjunto ordenado de valores numerados), function (tem um código executável associado, a função é chamada para executar esse código e retornar um valor calculável). Classes são definidas por construtoras e podem ser consideradas subtipos de Objeto.
